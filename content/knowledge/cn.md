chapter: 一、体系结构
title: 分层模型与四种时延
tags: 必考,计算
freq: 高
+++
**OSI 七层**：物理、数据链路、网络、传输、会话、表示、应用。
**TCP/IP 四层**：网络接口（主机-网络）、网际 IP、传输 TCP/UDP、应用。
**五层（教材常用）**：物理、链路、网络、传输、应用。每层向上提供服务，**对等层之间才有「协议」**，相邻层之间是服务接口（SAP）。

**数据封装**：应用消息 → 传输段(segment)+TCP头 → 网络数据报(datagram)+IP头 → 链路**帧(frame)**+帧头帧尾 → 比特流。注意名词对应：**链路层 PDU 是帧，网络层是数据报/分组，传输层是报文段**。

**四种时延（必算）**
- 发送时延（传输时延）= 数据帧长度 / 发送速率（与链路带宽有关）
- **传播时延 = 信道长度 / 电磁波传播速率**（约 2×10⁸ m/s，与带宽无关 —— 最大陷阱）
- 处理时延：路由器检查首部、查表
- 排队时延：取决于拥塞程度
- 总时延 = 四者之和。
- **带宽时延积** = 带宽 × 传播时延 = 链路上一共能有多个比特在飞（决定窗口下界）。
- RTT 往返时间；**k·RTT 决定发送效率**，高速长距离链路必须用大窗口。

**其他常考**：吞吐率受带宽、时延、协议开销共同限制；「宽带」只表示带宽宽，不代表时延小。

chapter: 二、物理层
title: 奈奎斯特、香农与复用
tags: 必考,计算
freq: 高
+++
**两个极限公式（分清用途）**
- **奈奎斯特（无噪声、理想低通信道）**：C = 2W·log₂M（W 为带宽 Hz，M 为电平/码元种类数）。注意「每 2Hz 带宽对应 1 波特」，**码元传输速率（波特）上限 = 2W**。
- **香农（有噪声）**：C = W·log₂(1 + S/N)，S/N 为功率比；题目给分贝时 **dB = 10·log₁₀(S/N)**，先换算回比值。
- 两式取**较小值**才是实际极限；给「要求的速率」反推需要的信噪比或带宽，是标准题型。

**概念区分**：数据（消息）、信号（电磁波）、**码元**（一个波形状态携带 log₂M 比特）、带宽（Hz 或 bit/s，注意语境）、信道（单工/半双工/双工）。

**传输方式**：串行/并行、单工/半双工/全双工、同步传输 vs 异步传输（起止式，靠起止符定界）。

**编码与调制**
- 数字基带编码：NRZ（无自同步、直流分量）、RZ、**曼彻斯特**（每码元中间跳变，自同步，以太网 10M 用过，效率 50%）、差分曼彻斯特（跳变表示 0/1 的约定不同）。
- 模拟调制：ASK/FSK/PSK/QAM（多比特一码元，QAM-16 = 4 bit/码元）。
- 信码与码型的转换、**4B/5B、8B/10B** 用于提高定时信息与直流平衡。

**信道复用**：FDM 频分、TDM 同步时分复用（固定时隙，可能浪费）、**统计时分复用 STDM**（按需分配，效率高）、WDM 波分（光纤）、CDM 码分（各站码型正交，抗干扰、保密，3G 使用）。

title: 组帧、差错控制与滑动窗口
tags: 必考,大题
freq: 高
+++
**组帧四法**：字符计数（首字段发长度，对硬件故障容忍差）、**字符填充的首尾定界法**（PPP，转义 ESC）、**比特填充的标志定界法**（HDLC/以太网类，连续 5 个 1 后插 0，接收端删 0）、违规编码法（曼彻斯特用非法电平）。

**差错控制**：检错（奇偶、CRC、海明）+ 重传。
- **停等协议**：发送窗口 = 接收窗口 = 1；序号只需 1 bit；信道利用率 = T帧/(T帧+RTT+Tack)。
- **后退 N 帧 GBN**：累积确认，发送窗口 **W_T ≤ 2ⁿ - 1**，W_R = 1；出错则整窗重发。
- **选择重传 SR**：只重发错帧，**W_T ≤ 2^(n-1)**，W_R = W_T（接收窗口必须能容下乱序帧）。
问「序号位数至少几位」时，把窗口需求代进上面的不等式反解。

**PPP 协议（选择题常客）**：面向字节、异步链路使用**字符填充**（0x7E 标志、0x7D 转义）、无序号、不提供可靠传输、有 FCS 检错；链路控制阶段 LCP + 网络控制 NCP（IPCP），认证 PAP（明文两次握手）与 CHAP（三次握手、MD5 挑战，口令不上网）。

chapter: 三、数据链路层
title: 以太网、CSMA/CD 与交换机
tags: 必考,计算
freq: 高
+++
**CSMA/CD（载波监听多路访问/冲突检测）**：先听后发、边发边听、冲突停发、**随机重发（截断二进制指数退避）**。
- 能检测冲突的前提是「发送时间 ≥ 往返传播时间 2τ」，即**最短帧长 = 2τ × 数据率**。
- 标准 10 Mb/s 粗以太网：争用期 51.2 μs（= 10 μs 传播 ×5 段？按 2500m、5-4-3 规则），**最小帧 64 B**；**最大网段跨距受最短帧限制** —— 数据率提高后若保持帧长，覆盖范围必须缩小（这是「快速/千兆以太网缩短最大网段、改用全双工交换机」的原因）。
- **CSMA/CD 只用于半双工**；全双工交换机不需要冲突检测。
- 帧格式：前导码 7B + SFD 1B（不计入帧长）、目的/源 MAC 各 6B、类型 2B、数据 46~1500B、FCS 4B。**数据不足 46B 要填充**（填充也计入长度、算 CRC）。
- MAC 地址 48 位，**前 24 位 OUI**；组播地址最高字节最低位为 1（01-00-5E…），广播 FF-FF-FF-FF-FF-FF。

**交换机（二层）**：端口各成一冲突域、**所有端口同一广播域**；**自学习**（收到帧记下源 MAC→端口，查目的 MAC 表：命中就转发、不命中就泛洪，目的地址是广播/组播也泛洪）；转发方式：直通式（快、不检错）、存储转发（可靠、延迟大）、碎片隔离。
VLAN：逻辑划分广播域，隔离广播风暴，跨 VLAN 通信需要三层设备（或单臂路由）。
**802.11（WLAN）**：CSMA 不能边发边听 → 用 **CSMA/CA**：确认机制 + **RTS/CTS** 解决隐藏站问题、虚载波监听（NAV）；DCF 竞争、PCF 轮询；基础结构模式（AP）与 ad-hoc。

chapter: 四、网络层
title: IPv4 地址、CIDR 与子网计算
tags: 必考,大题
freq: 高
+++
**分类地址**：A 1.0.0.0~126（/8）、B 128~191（/16）、C 192~223（/24）、**D 224~239 组播**、E 保留。
**特殊地址**：0.0.0.0（本机默认/未指定）、127.x 环回、全 0 主机号=网络地址、全 1 主机号=定向广播、0.0.0.0/本网络。
**私有地址**：10/8、172.16/12、192.168/16 —— 公网上不可路由，靠 NAT 出网。

**子网与 CIDR 计算三步法**
1. 掩码连续的 1 的个数 = 前缀长度 /n；主机位 h = 32-n → **可用主机数 = 2^h - 2**。
2. 块大小（步长）= 2^h，网络地址是该块大小的整数倍：`网络号 = IP 与掩码`。
3. 广播地址 = 网络号 + 主机位全 1。
例：172.16.8.130/25 → 块 128，网络 172.16.8.128，广播 172.16.8.255，可用 126 台。

**CIDR 超网/聚合**：取各网络地址的**公共前缀**（写成 a.b.c.d/最长公共前缀长度），聚合后路由表项减少。
**代理 ARP**：主机以为目标在同一网段，由网关用自己的 MAC 应答。
**DHCP**：DISCOVER(广播)→OFFER→REQUEST→ACK，UDP 67/68，租期概念，可给 IP/掩码/网关/DNS。

**IPv6**：128 位冒号十六进制（:: 压缩零、只能一次）、**无校验和**、固定 40 字节基本首部 + 扩展首部、**没有广播**（用组播 + 任意cast）、邻居发现 NDP（替代 ARP，用 ICMPv6）、首部中 **下一个首部** 字段取代 IPv4 协议字段、流标签 QoS。过渡：双协议栈、隧道、NAT-PT。

id: cn-06
chapter: 四、网络层
title: ARP、ICMP、路由协议与 NAT
tags: 必考,大题
freq: 高
+++
**一次跨网段访问的完整链路**（大题常要求串起来）：应用 DNS 解析 → ARP 找**默认网关**的 MAC → 封装 IP（源本机 IP、目的对端 IP）+ 以太帧（源本机 MAC、目的网关 MAC）→ 路由器逐跳改写 **TTL 减 1、MAC 地址重写、重算首部校验和**（IP 地址不变）→ 目的主机回包。

**ARP**：已知 IP 求 MAC，**同网段广播请求、单播应答**；ARP 缓存有老化时间。不同网段时 ARP 请求的是网关 MAC。
**ICMP**：封装在 IP 数据报里（协议号 1），差错报告（目的不可达 3、源结束/超时 11、参数问题 12、重定向 5）与询问（回送请求/应答 8/0）。
- **ping** 用回送请求/应答测通断与 RTT。
- **traceroute/tracert** 逐步把 TTL 设 1,2,3… 触发「超时」差错，从而得到路径上每跳地址。

**路由算法与协议**
- 静态 vs 动态；域内（IGP）与域间（EGP）。
- **RIP**：距离向量，度量=跳数，**最大 15 跳、16 表示不可达**，每 30 s 与邻居交换整张表，封装在 **UDP 520**。缺点：收敛慢、计数到无穷 → **水平分割、反向路由中毒、毒性逆转、抑制定时器**。
- **OSPF**：链路状态，洪泛 LSA、各结点跑 **Dijkstra**、区域划分（骨干区域 0）、封装在 IP（协议号 89）、用 Hello 维护邻居、收敛快、支持等值 Cost 多路径、安全认证。
- **BGP**：自治系统 AS 之间，路径向量、基于 **TCP 179**（可靠），策略路由。
- 路由表查找按**最长前缀匹配**。

**NAT/NAPT**：私有地址↔全局地址转换，**端口地址转换 PAT 用端口号区分内部主机**，一台公网 IP 可服务大量内网主机。缺点：外部无法主动发起连接（需端口映射/ALG），破坏端到端原则。

chapter: 五、传输层
title: TCP 与 UDP：报文、连接与可靠性
tags: 必考,大题
freq: 高
+++
**UDP**：无连接、不可靠、**首部仅 8 字节**（源/目的端口、长度、校验和）、支持单播/组播/广播、面向报文（不合并拆分）。适合实时、DNS、SNMP、音视频。
**TCP**：面向连接、字节流、可靠有序不丢不重、**首部 20~60 字节**（含选项：MSS、窗口缩放、SACK、时间戳）、点对点。

**TCP 关键字段**：序号（32 位，按**字节**编号）、确认号（期望的下一个字节序号）、数据偏移、保留、6 个控制位 **URG ACK PSH RST SYN FIN**、窗口（16 位，配合窗口缩放）、校验和（伪首部参与）、紧急指针。

**三次握手**：SYN(seq=x) → SYN+ACK(seq=y, ack=x+1) → ACK(ack=y+1)。
为什么不能两次：防止**已失效的 SYN** 突然到达使服务端建立无用连接、双方初始序号都要被确认。半连接队列/全连接队列、SYN 洪泛。
**四次挥手**：FIN → ACK →（被动方发完数据再）FIN → ACK。主动方进入 **TIME_WAIT = 2MSL**：保证最后一个 ACK 可达（丢了对方会重发 FIN）+ 让本连接的旧报文在网络中消逝。

**可靠传输**：序号 + 确认 + 超时重传 + 校验 + 重传窗口。
- RTT 估计（教材/Karn-Partridge）：`SRTT = (1-α)SRTT + α·RTT样本`，`RTTDV = (1-β)RTTDV + β|SRTT-RTT样本|`，**RTO = SRTT + 4·RTTDV**；只用非重传报文计算 RTT，超时后指数退避。
- **快重传**：收到 **3 个重复 ACK** 立即重传该段，不等超时；**快恢复**：ssthresh = cwnd/2，cwnd = ssthresh 后进入拥塞避免。
- 累积确认 vs 选择确认 SACK（解决**随机丢包导致的成串重传/retransmission 混乱**）。

**流量控制**：接收方通过 ACK 中的 **rwnd** 告知自己的接收缓存剩余；发送方保证「已发未确认 + 新发 ≤ rwnd」。rwnd=0 时发送方启动**零窗口探测报文**（含 1 字节、会被对端回应）避免死锁；接收方要避免通告小窗口（**糊涂窗口综合征**），可等窗口达到 MSS 或缓存一半再通告，发送侧可用 **Nagle 算法**合并小包。

id: cn-08
chapter: 五、传输层
title: 拥塞控制：慢开始与拥塞避免
tags: 必考,大题
freq: 高
+++
**四个算法**：慢开始、拥塞避免、快重传、快恢复。
- 慢开始：cwnd 从 1 MSS（或 2~4，按题目）起，**每收到一个 ACK 就 cwnd+1** → 每经过一个 RTT **翻倍**（指数增长），直到达到门限 ssthresh。
- 拥塞避免：cwnd ≥ ssthresh 后，**每经过一个 RTT 才 +1 MSS**（加法增大 AIMD）。
- **超时（丢包）**：ssthresh = cwnd/2，**cwnd = 1**，重新慢开始（乘法减小 MD）。
- **3 个重复 ACK（快重传）**：ssthresh = cwnd/2，**cwnd = ssthresh**，直接进拥塞避免（Reno）；SACK/Tahoe 的差别题里会说明，按题给规则算。

**大题算法（逐轮列表）**：把「传输轮次 n」与「cwnd」对应：n=1..k 指数（1,2,4,8…）到 ssthresh 后线性（+1）。若第 i 个轮次超时，则下一轮从 1 重新开始、门限为 i 时刻值的一半 —— 画折线图与算「发送一个 100KB 文件需要多少 RTT」都是同一路数。

**其他必考概念**：拥塞窗口 vs 接收窗口，**实际发送窗口 = min(cwnd, rwnd)**；拥塞是「网络太多包」（全局），流量控制是「接收方来不及收」（端到端），两者机制不同。
RED/WRED 随机早期检测、ECN 显式拥塞通知、CUBIC/BBR（新算法思想：按带宽时延积定窗，不靠丢包探测）属于概念层面。

chapter: 六、应用层
title: DNS、HTTP、邮件与 DHCP
tags: 必考,选择
freq: 高
+++
**DNS**：把域名映射到 IP。服务器三类：**根**、**顶级（TLD）**、**权限（权威）**域名服务器；另有本地域名服务器（resolver，多数缓存）。
- 主机→本地：**递归查询**；本地→根/顶级/权限：**迭代查询**（各告知下一步找谁）。
- 端口 53，查询用 **UDP**，**区域传送/大数据响应用 TCP**。
- 记录类型：A（名→IPv4）、AAAA、CNAME（别名）、NS、MX（邮件）、PTR（反向）。缓存有 TTL。
- 从浏览器输入网址到页面出现，答全会加分：DNS（浏览器缓存→本地→递归/迭代）→ TCP 三次握手（+TLS）→ HTTP 请求 → 服务器处理 → 响应 → 渲染，其间还有 ARP、路由、NAT。

**HTTP**：无状态。**请求** = 请求行（方法 空格 URL 空格 版本）+ 首部 + 空行 + 主体；方法 GET/POST/HEAD/PUT/DELETE；**响应** = 状态行（版本 状态码 短语）+ 首部 + 主体。
状态码：**1xx** 信息、**2xx 成功**（200、204）、**3xx 重定向**（301 永久、302 临时、304 未修改走缓存）、**4xx 客户端错**（400、401 未授权、403 禁止、404 不存在）、**5xx 服务器错**（500、503）。
HTTP/1.0 每请求一连接；**1.1 持久连接（keep-alive）+ 流水线**；1.1 用 **Content-Length / chunked** 定界；无状态靠 **Cookie/Session** 保持登录态。
**HTTPS = HTTP + TLS/SSL**，端口 443，提供机密性、完整性、身份认证（数字证书）。

**邮件**：**SMTP**（推，端口 25，只传 7 位 ASCII，MIME 扩展支持附件/中文）、**POP3**（拉，110，下载后删除/副本可选）、**IMAP**（143，邮件留在服务器、支持文件夹同步）。
**FTP**：控制连接 21（整个会话保持、发命令）+ **数据连接**（每个文件一次）；主动模式服务器用 20 端口回连客户端，被动模式由服务器开临时高端口等客户端连。
**Telnet/SSH**：远程登录，SSH 22 加密。
**DHCP**：见网络层，客户端广播获取配置。

chapter: 七、网络安全
title: 加密、签名、证书与防火墙
tags: 选择
freq: 中
+++
**两类密码体制**
- 对称加密（DES/AES）：**加解密同钥**，速度快，适合大量数据；难点是**密钥分发与管理**。
- 公钥加密（RSA/ECC）：公钥加密、私钥解密，密钥管理简单，但**慢**（比对称慢几个数量级），所以实际用「**公钥加密会话密钥 + 对称加密数据**」的混合方案（TLS 就是这个）。

**报文鉴别与数字签名**
- 报文摘要（MD5 已不安全、SHA 系列）**单向**，用于完整性校验。
- **数字签名 = 用发送方私钥对报文摘要加密**，接收方用其公钥验证；作用：真实性、完整性、**不可否认**。
- 混淆方向别记反：**加密用对方公钥，签名用自己私钥**。

**公钥基础设施 PKI/CA**：CA 用自己的私钥给「公钥 + 身份」签名，形成**数字证书**（X.509：版本、序列号、签名算法、颁发者、有效期、主体、主体公钥、扩展、证书签名）。证书撤销用 CRL/OCSP。

**TLS 握手（简化）**：ClientHello（随机数、密码套件）→ ServerHello + 证书 + 服务端随机数 → 客户端验证证书、生成预主密钥并用服务器公钥加密 → 双方由三个随机数导出对称会话密钥 → 切换加密通信。

**IPSec**：网络层安全，AH（认证、完整性）与 **ESP（加密 + 认证）**，传输模式与隧道模式（隧道模式保护整个内层 IP 头，用于 VPN）。
**防火墙**：包过滤器（按五元组，网络层）、应用网关（代理）、状态检测；缺点：**不能防内部攻击、不能防绕过它的连接（如拨号/加密隧道）、不防病毒文件**。

**1. 子网划分/聚合**
写清 /n、掩码、块大小 2^h，列表枚举各网段的网络号与广播地址；要求「最少地址块」时用公共前缀聚合。反向题「给主机数求掩码」：h = ⌈log₂(主机数+2)⌉ → n = 32-h。

**2. 时延与效率**
把「发送时延 = 帧长/速率」「传播 = 距离/2×10⁸」分开算，总时间 = 源发送 + 传播 + 每跳处理与排队 + 目的发送。停等协议的信道利用率 = T发送/(T发送+T传播+T确认(+处理))；给出「链路长度与带宽」时要意识到**带宽时延积**决定必须窗口大小。

**3. CSMA/CD 与帧长**
最短帧长 L_min = 2τ·R（τ 为单向传播时延）；反过来问「网络最大跨距」：τ = L_min/(2R) → 距离 = τ × 传播速率。数据率提高 R' 后，若仍要求 64B 帧，最大距离缩为原来的 R/R'。

**4. TCP 拥塞窗口**
按轮次列表：慢开始指数 → 到 ssthresh 转线性 → 标出超时或三个重复 ACK 的那一轮 → 按规则改写 ssthresh 与 cwnd（超时归 1、快恢复等于新 ssthresh）。最后把各轮发送的 MSS 数累加，换算成字节回答「传完 N 字节需要几轮/几个 RTT」。

**通用检查**：单位（Mbps vs MB/s、μs vs ms）、是否要算 ACK 的传输、是否算帧头帧尾开销、组播/广播是否计入 —— 这四类「忘了算」占失分的大多数。
