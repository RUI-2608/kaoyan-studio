# 考研备考台（计算机 · 平板适用版）

一套给自己用的考研复习资料：数学（一）、数学（二）、408 计算机、英语（一/二）的**历年真题 + 答案 + 逐题解析**，
外加按 408 大纲手写的**知识卡片手册**。可以在平板上离线用，也能导出 A4 的 PDF 拿进 GoodNotes 手写。

---

## 一、怎么用

### 1. 放到平板上（离线）
把整个 `web/` 文件夹拷到平板（iPad 用「文件」App，安卓用任意文件管理器），
点开 `web/index.html` 即可 —— 不需要服务器、不联网，公式渲染用的 KaTeX 也在包里。

> 为什么不是 `.json` 数据：浏览器在 `file://` 下会拦住本地 JSON 的读取，
> 所以数据全部打成 `.js`（`window.KY[...] = {...}`），双击就能跑。

### 2. 本地电脑预览
```bash
node scripts/serve.mjs            # http://127.0.0.1:8137/
```

### 3. 做题的两种模式
| 模式 | 行为 | 适合 |
| --- | --- | --- |
| **背题** | 点一下选项就判分并展开答案 + 解析 | 对答案、过第二轮 |
| **考试** | 整卷作答、计时，最后「提交判分」一次性出结果 | 掐表刷套卷 |

收藏（★）、错题（✗）、每题笔记、做题进度都存在**这台设备的浏览器里**；
换设备用顶栏「进度备份」导出 JSON，再在新设备上导入。

### 4. PDF（手写批注用）
`pdf/` 下 65 份 A4：
- `知识手册-数据结构 / 计算机组成原理 / 操作系统 / 计算机网络 / 数学（一 二）公式与结论.pdf`
- `数学试卷-<年份> 年数学（一）.pdf`、`数学试卷-<年份> 年数学（二）.pdf`（题后留作答线，答案与解析在末尾另起页）
- `408试卷-<年份> 年计算机学科专业基础.pdf`（17 年，同上）

重出：`node scripts/build-pdf.mjs [手册|数学|数学二|408|all]`（用无头 Edge 打印，公式与屏幕上完全一致）。

### 外来答案是怎么被信下来的
- **第二来源要自证是这套卷子**：它自己也印了题干，于是拿主源题干逐题比对（去空格标点、比前缀 + 字符重合度）。
  实测同一年同题重合度中位数 1.00，故意把 2010 与 2013 错位相比最高只有 0.33，所以卡 80% 这条线；
  2009 一度被「2009-2017 合集」那份文件带偏，就是这道闸拦下的。
- **第三来源只印答案不印题干**，没法比题干，就改成**标定通道**：先拿它撞已经确认的年份，
  实测在 2016/2019 年 80 题上与已核实答案 100% 一致，才允许它去补 2020–2022。
- **只认「题号和字母成对出现」的答案**：卷首那种竖排表按文字流读出来是 1,9,17,25,33,2…，
  位置一错整卷全错。原来那条「40 个字母按位置对应」的通道实测与另一来源在 2010 年 29/40 处不一致，已整条删除。
- 同一题两个来源不一致时不静悄悄取一个：两条都写出来，挂「务必对原卷」旗标（本轮 17 年 0 处不一致）。

## 四、没做到的事（这些不是「查过了没有」，是「还没查出来」）

1. **408 还缺 2024、2025 两年的答案**：这两年的答案卷（含另找到的回忆版 PDF）抽出来是 0 个文字，纯扫描图。
   没做 OCR 硬认答案 —— 认错一个字母会静悄悄把整卷带歪。缺的题逐题挂着「答案待核实」，旁边就是原卷/答案 PDF。
2. **1987–2003、2021 只做原文阅读**：这些年份的转录里题号被打散（`11)`、`(2)`、`4）` 混排），接不上题号就不做结构化 —— 宁可只给原文，也不猜题号。
3. **数二 15 年只做原文、148 道题只有引用**：原料是「题干 + 解答」合订本，早期年份解答只写「同试卷一第 N 题」；
   带脚注的「N」指代不唯一，所以不代抄题干，只给跳转到数一同年卷的链接。
4. **408 有 76 道题含图**（树、电路、网络拓扑）：文字版 PDF 不含图形，这些题都标了「含图，请对原卷」。
5. **题目所属科目（数据结构/组成/OS/计网）是按关键词猜的**，页面上写明了这一点，题号-科目官方对应表各年不同；卷面顺序才是真的。
6. **政治整块没做**：真题原文与押题受版权限制，本机可达的源里没有。
7. **知识卡上的「高频」是人工判断**，不是官方统计；分值与题型以当年《考试大纲》《考试分析》为准。

## 五、重新构建

```bash
npm i                                  # 只需要 katex
# 数学（一）/数学（二）/英语的原料是手工 sparse clone 进来的（没有脚本，命令如下）：
#   git clone --filter=blob:none --no-checkout --depth 1 <repo> _vendor/<name>
#   git -C _vendor/<name> sparse-checkout set --no-cone 'papers/**' 'solutions/**/*.md' 'solutions/**/*.jpg'
#   git -C _vendor/<name> read-tree -mu HEAD
node scripts/build-math.mjs            # 数学（一）：抽题、对齐试卷与解析、配图搬运、分档
node scripts/build-math2.mjs           # 数学（二）：按年份切分解答、共题只记引用
node scripts/build-english.mjs         # 英语：整形 + 配图
node scripts/fetch-408-alt.mjs         # 408 第二来源：13 份答案本（tree+blob API 单文件取）
node scripts/fetch-408-third.mjs       # 408 第三来源：JDC2001 的答案 PDF（断线用 -C - 续传）
node scripts/build-408.mjs             # 408：抽文字、三来源交叉、题干闸门、含图旗标
node scripts/build-knowledge.mjs       # 知识卡片（改 content/knowledge/*.md 后跑）
node scripts/audit.mjs                 # 数据体检：不过就不许端上桌
node scripts/shot.mjs                  # 无头 Edge 拍真机尺寸截图（iPad 横竖屏 + 手机）
node scripts/build-pdf.mjs all         # A4 PDF 套件
```

原料仓库在 `_vendor/`（`git clone --filter=blob:none --no-checkout` + sparse-checkout，只拉需要的文件），
`.gitignore` 已排除；`web/data/` 是生成物但**故意入库**，检出即可直接用。

### 体检跑什么
- 结构不变量：题号、选项数、题干长度、id 唯一、缺答案必须挂旗标（数学 / 数二 / 408 / 英语各一套）
- **回原文对账**：数学每年「原文里印了几个【答案】」对得上库里存了几条
- **答案交叉验证**：408 已核实答案与解析正文里显式写的「故选 X」互相打脸就点名；一致 52/52
- **闸门复查**：外来答案只能来自题干比对 ≥80%（第二来源）或通道标定 ≥90%（第三来源）的年份，且逐题写明出处文件
- 公式渲染：13056 处 KaTeX 全过
- 文件在位：`index.html` 的本地引用、站点里挂的 68 个 PDF/配图逐个查

最近一次结果：`_research/audit-report.json`（体检通过 16 项、如实提醒 39 条）。
